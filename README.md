# C Day 81 - Average of Positive Numbers

This C program calculates the average of positive numbers entered by the user.

## Example

Input numbers: `10, -5, 20, 0, 30`

Output:
```text
Average of positive numbers = 20.00
```

## Concepts Used

- Variables
- `for` loop
- `if-else` statement
- Counter variable
- Type casting using `(float)`
- Average calculation

## How It Works

The program accepts numbers from the user and adds only positive numbers to the sum. It counts these numbers and calculates their average. If no positive numbers are entered, it displays a suitable message.

## What I Learned

I learned how to calculate the average of numbers that satisfy a condition using C.
